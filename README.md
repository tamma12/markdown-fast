A fast, dependency-free Markdown renderer that produces byte-identical HTML to marked 18.1.3 (CommonMark 0.31.2 + GFM), rendering the 720-case practice set in ~1.6 seconds.

## Run it

```sh
node --experimental-strip-types main.ts <input-dir> <output-dir>
```
